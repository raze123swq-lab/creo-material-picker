# Creo 材料面板

当前版本 **v1.1.0** · Windows · Creo Parametric 12.x

中文材料选择面板支持名称搜索、类别筛选、牌号与密度说明、应用到当前零件，以及单独读取当前零件质量并显示为克（g）。已有材料的零件无需再次应用材料。

安装包提供 28 个重量估算用通用材料和 11 个带厂商牌号的材料，并扫描新电脑上 Creo 自带的 `.mtl` 文件。总数随 Creo 安装内容而变化，本机 Creo 12.4 为 262 项。通用 ABS、PC-ABS 等未指定厂商牌号，面板会明确标记。

## 安装与使用

需要 64 位 Windows、Windows PowerShell 5.1 和 Creo Parametric 12.x。保存工作并退出 Creo，完整解压仓库，运行 `Install.cmd`。安装器校验材料包、定位 Creo、备份用户映射键配置，并创建桌面入口。

启动 Creo，打开零件，然后打开桌面的「Creo 材料面板（便携版）」。单击材料查看详情，双击或点击「应用到当前零件」进行分配。已赋材的零件可直接点击「读取当前质量 (g)」。结果窗口可复制质量，确认前可勾选自动关闭 Creo 的质量相关窗口。若收不到本次报告，核对 Creo 工作目录并用「报告目录…」指定位置。首次使用请用测试零件核对材料与质量。

## 版本约定

使用 `主版本.次版本.修订号`。修复递增修订号，新增兼容功能递增次版本号，不兼容变化递增主版本号。`v1.0.0` 是后续升级基线，每次发布更新 [CHANGELOG.md](CHANGELOG.md)，并保留可回退的安装包。

本面板使用 Creo 映射键和 `.mtl` 文件，不属于 PTC 官方软件。
